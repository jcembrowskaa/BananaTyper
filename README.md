Kilka słów o 'Banana Typer'
Banana Typer to gra typu monkey typer, w której zadaniem gracza jest wpisywanie pojawiających się słów, zanim znikną na drugim końcu ekranu.
Im dłuższe słowa i trudniejsze opcje tym więcej punktów.Gracz traci życie za każde słowo, które dotrze do końca ekranu. 
Gra kończy się, gdy liczba pomyłek przekroczy dostępne życia.


Skróty klawiszowe działające w czasie gry:
ctrl+o - pauza + wyświetlenie skrótów klawiszowych
ctrl+p - wyłączenie/włączenie podświetlenia napisów
ctrl+d - włączenie/wyłączenie disco mode (wyrazy generowane są w losowych kolorach)
esc - wyjście do opcji
strzałka w górę - przyspieszenie słów
strzałka w dół - zwolnienie słów
strzałka w prawo - zwiększenie częstotliwości pojawiających się słów
strzałka w lewo - zmniejszenie częstotliwości pojawiających się słów
a-z,A-Z - wpisywanie słów
backspace -usuwanie ostatniej litery

skrót działający w każdym oknie:
esc - cofa o jeden ekran

ustawienia:
punkty to = długość słowa * mnożnik za szybkość * mnożnik za częstotliwość * mnożnik za ilość żyć
speed - szybkość przesuwania się słów
| Wartość | Opis                 | `speed` | `speedPoints` |
| ------- | -------------------- | ------- | ------------- |
| sloth   | Bardzo wolne tempo   | 100     | 1.0           |
| monkey  | Średnie tempo        | 200     | 1.5           |
| gibbon  | Bardzo szybkie tempo | 300     | 2.0           |

frequency - częstotliwość pojawiania się słów
| Wartość | Opis          | `spawnTime` (s) | `frequencyPoints` |
| ------- | ------------- | --------------- | ----------------- |
| deluge  | Bardzo rzadko | 2.0             | 2.5               |
| storm   | Rzadko        | 1.5             | 2.0               |
| shower  | Często        | 1.1             | 1.5               |
| drop    | Bardzo często | 0.6             | 1.0               |

lives - zakres od 1 do 10
| Życia | `livesPoints` |
| ----- | ------------- |
| 1     | 1.6           |
| 3     | 1.0           |
| 10    | 0.3           |

size - rozmiar czcionki
| Wartość  | Opis           | `fontSize` |
| -------- | -------------- | ---------- |
| seed     | Małe litery    | 20         |
| seedling | Średnie litery | 30         |
| tree     | Duże litery    | 40         |

length - maksymalna długość słów
| Wartość   | Opis                 | `maxLength` |
| --------- | -------------------- | ----------- |
| ant       | Bardzo krótkie słowa | 3           |
| earthworm | Krótkie słowa        | 6           |
| lizard    | Dłuższe słowa        | 10          |
| snake     | Najdłuższe słowa     | 15          |

Ranking:
Ranking wyświetla Top 5 najlepszych graczy według zdobytych punktów.
Jeśli gracz (np. Mario) zdobył wcześniej 20 punktów, a później uzyska 40 punktów,
to w rankingu zapisana zostanie tylko najwyższa wartość – w tym przypadku 40 punktów.
Starsze, gorsze wyniki danego gracza są nadpisywane.
